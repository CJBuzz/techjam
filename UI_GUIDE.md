# Dashboard guide

## What the dashboard does

`app.py` displays predictions generated by `infer.sh`. It does not load model weights or run inference in the browser.

The workflow is:

```text
images/ -> infer.sh -> output.json -> app.py -> Streamlit dashboard
```

## Generate results

Place images in `images/`, then run:

```bash
./infer.sh
```

Defaults:

- Input directory: `images/`
- Checkpoint: `artifacts/robust_laplacian_fft.pt`
- Output: `output.json`

To use another checkpoint:

```bash
./infer.sh images artifacts/hybrid_detector.pt output.json
```

## View results

Start Streamlit:

```bash
uv run streamlit run app.py
```

Each image card shows:

- The image loaded from its `image_path`;
- The calibrated `pred` probability;
- A color spectrum from green (human/real) through yellow (uncertain) to red (AIGC/AI);
- A black marker showing the image's position on that spectrum.

A probability near 0 means the model considers the image likely real. A probability near 1 means it considers the image likely AIGC-generated. A value around 0.5 should be treated as uncertain.

Use **Refresh results** after changing `output.json` or adding new images.

## JSON contract

The output must be a JSON array. Every record contains exactly these fields:

```json
[
  {
    "image_path": "images/image_001.jpg",
    "pred": 0.9374
  }
]
```

`pred` must be a number between 0 and 1. The dashboard accepts paths produced by the inference script as well as image filenames resolvable under `images/`.

## Troubleshooting

- **No output.json found:** Add images and run `./infer.sh`.
- **No images appear:** Check that the paths in `output.json` point to existing files.
- **Checkpoint error:** Pass the correct checkpoint as the second `infer.sh` argument.
- **Stale results:** Run inference again and click **Refresh results**.
- **Port in use:** Run `uv run streamlit run app.py --server.port 8502`.
- **Missing dependencies:** Run `uv sync`.
